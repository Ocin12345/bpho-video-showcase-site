01 / basis anatomy

Separate radius from angle.

The m sweep changes only Yℓm; every state in the selected subshell shares the same normalized Rnℓ.

02 / extensions

Three meanings of “combine”.

The algebra changes with the physical question. Amplitudes interfere inside one orbital; occupied independent orbitals contribute probabilities to an electron density.

Magnetic-state superposition

Coherent amplitudes

ψ = cos α Yℓm + eiδ sin α Yℓ,m+1

At integer endpoints this is an L̂z eigenstate. Between them it is a normalized superposition, so “fractional m” is only a path label.

Multi-electron atom

Occupied-orbital density

ρNe(r) ≈ Σi Ni|ψi(Zeff)|²

Effective charge mimics screening. Occupations enforce the shell count, but a product of hydrogenic orbitals omits dynamical electron correlation.

Multi-centre molecule

Linear combination of AOs

ψ = ΣA cAφA · cᵀSc = 1

Atomic amplitudes interfere across nuclei. The overlap matrix S—not Σc² alone—sets the molecular-orbital normalization.

Interpretation boundary

A basis is not a many-body solution.

The neon view is an independent-electron, effective-charge density. The molecular views are minimal-basis LCAO orbitals at user-chosen geometries. Neither optimizes total energy, antisymmetrizes a displayed many-electron wavefunction, or calculates correlation.
