# BPhO video showcase

A separate, focused presentation site for the BPhO Computational Challenge 2026
quantum mechanics project. The current stage contains the homepage only.

## Local preview

From this directory, run:

```bash
python3 -m http.server 4186
```

Then open `http://127.0.0.1:4186/`.

The site is static and uses relative paths, so it can be published directly with
GitHub Pages after the homepage is approved.
